## 初版观察记录

观察日期：2026-10-21；公开参考：<https://www.leleo.top/>。

最初文本抓取仅能得到 SPA 外壳，随后使用浏览器成功显示公开页面。实际观察到的参考站更接近个人门户：大幅插画背景，圆形头像，半透明的圆角标签卡片，动态打字文案，时间显示、社交图标以及“部署项目”入口列表。公开导航包含博客、图库、二级域名、网盘等项目入口，并有赞助名单分页。没有进入其私有区域，也未把个人主页当成已经查看过文章详情的证据。

借鉴的是背景营造氛围、卡片组织信息、身份标识和轻量动态文案。没有复制对方插画、头像、文章、图表、应用代码或统计脚本。

本站采用原创 SVG 山峦与湖面作为背景，青绿色主色，米金色月亮作为点缀；系列封面分别用数据库、虚拟窗口和网络节点的原创几何线条表达主题。SVG 可直接维护且体积很小，不依赖远程图片服务。

信息架构转为学习型博客：透明导航 → 全屏首页 → 三个分类入口 → 最新文章与个人介绍/公告；阅读页使用主题原生目录、代码工具栏、上下篇和推荐内容。学习路线提供稳定的 1～5 顺序，归档按发布时间排列，标签跨系列联结内容。

导航：首页、学习路线、分类、归档、标签、关于；搜索置于导航，RSS 置于个人卡片和页脚。友情链接暂未启用，避免虚构朋友站点。

减少无关动画，未启用粒子、鼠标烟花、播放音乐、开屏加载或访问统计。背景使用本地资源，使用原生图片懒加载；搜索数据在需要时加载；代码高亮在构建时完成。尊重 prefers-reduced-motion，页面动画被取消，副标题显示静态文案。

个性化配置在 `_config.butterfly.yml`，外观扩展在 source/css/custom.css，首页入口在 source/js/custom.js，不修改主题源文件。三个前端库按需本地发布，避免完整主题扩展包引入不使用的评论与图表依赖。
