## 来源与整理范围

作者提供 `Mysql.pdf`，219 页，创建于 2021 年，包含数据库基础至分页的知识与大量问答和界面截图。已提取全文和 PDF 书签，按知识出现顺序整理 19 篇文章，主题与原页码对应关系见 `source/_data/mysql-series.json`。提取的原始文字、页面截图仅留在忽略的 tmp 目录；没有公开上传原 PDF、页脚广告或问答答案。

文章采用重新组织的中文讲解、统一员工/部门/账户样例、原创 SVG 图解、图示逐步解释与相邻篇导航。删除原文实时反馈、题目选项、答案、独立练习。图示覆盖应用与数据库关系、安装阶段、对象层级、选列筛行、内外连接、自连接、分组、子查询、联合索引、事务时间线与分页等。图形不直接复制培训机构商标或页面截图。

## 原稿主要修正

- 使用 MySQL 8.4 为明确基线，不沿用旧稿“最新版本”与旧安装窗口按钮。
- 新示例使用 utf8mb4，不用整数显示宽度与 ZEROFILL 表示容量。
- 说明 VARCHAR 和 TEXT 的字节/字符边界、DECIMAL 精度、文本排序规则与二进制比较，不采用固定类型速度排名。
- LENGTH 是字节长度，CHAR_LENGTH 是字符数；数字函数 TRUNCATE 要提供两个参数。
- SELECT 可以没有 FROM；日期差使用日期函数，不靠日期字符串直接相减。
- GROUP BY 不保证排序；COUNT(*) 不排除含空列的记录；明确 ONLY_FULL_GROUP_BY。
- 修正非等值示例的区间重叠；解释外连接 WHERE 过滤与全外效果的 UNION ALL 反连接分支。
- 多列索引是否使用依实际计划判断，不将最左前缀概括为所有情况下的绝对规则。
- 区分自动提交、显式事务、DDL 隐式提交、快照读和锁定读，不写 TRUNCATE 不记日志。
- CREATE USER 与 GRANT 分开，正常账号管理通常不需要额外 FLUSH PRIVILEGES。
- SQL 导出使用 result-file 避免依赖 PowerShell 的重定向编码；恢复到独立验证库。
- LIMIT 配合稳定 ORDER BY，并说明偏移分页与继续查找的差异。
