## 依赖审计与适用边界

本次联网 `npm audit` 报告 11 项（9 high、2 moderate），来源包括 braces 的深层模式拒绝服务与 sprintf-js 的精度参数拒绝服务，传递到 Hexo、CLI、搜索/Sitemap 生成器等构建依赖。报告的修复建议涉及将核心回退到 Hexo 3 等旧版本，不适合作为当前同代兼容修复，因此未运行 `npm audit fix --force`。

未把这些告警描述为已修复。构建与本地预览只面向可信内容，服务绑定 127.0.0.1；生产部署只上传静态 public 产物。应持续跟踪 Hexo 与其上游修复。离线锁文件操作曾输出 0 vulnerabilities，该输出不构成联网审计通过证据。
