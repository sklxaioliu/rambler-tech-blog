## 学习目标

分清宿主机、客户机、虚拟化软件与镜像文件，能根据自己电脑的资源规划第一台实验虚拟机。本系列使用 VMware Workstation Pro 的桌面虚拟化思路，其他产品的界面名称可能不同。

<!-- beginner-revision-2026-10-22 -->

## 先用一个例子理解

### 把真实电脑想成一栋房子

宿主机是整栋房子，虚拟机是其中划出的独立房间。每个房间有自己的系统和文件，但仍共享真实房子的水电，也就是 CPU、内存、磁盘等资源。给房间分资源，不等于凭空创造新硬件。

ISO 像安装光盘，虚拟磁盘像房间里的储物柜。安装完成后拔掉光盘，系统仍在虚拟磁盘里；只保存 ISO，却不保存虚拟磁盘，不能保留你装好的系统和笔记。

分配4GB内存是告诉软件客户机运行时需要这份内存；把磁盘上限设40GB，不代表立刻把宿主所有空闲空间吃完，也不代表以后一定够用。

## 基础知识：在一台电脑里模拟另一台电脑

宿主机是你真实使用的 Windows 电脑；客户机是虚拟机中安装的操作系统。虚拟化软件向客户机提供虚拟 CPU、内存、网卡和磁盘，并协调真实硬件的使用。ISO 文件类似安装光盘，虚拟磁盘文件则保存安装后的系统和数据。

虚拟机不是远程桌面。远程桌面是一种访问方式，可以连接物理机也可以连接虚拟机。虚拟机也不同于容器：常见容器共享宿主内核，完整虚拟机可以运行自己的内核。

隔离能降低误操作影响，但不等于绝对安全。共享文件夹、剪贴板、USB 直通和桥接网络都会扩大客户机接触宿主或局域网的范围。初学时只安装可信系统与工具。

## 操作步骤：先检查电脑

1. 打开任务管理器的“性能 → CPU”，检查“虚拟化”是否启用。
2. 如果未启用，查电脑厂商文档中的 Intel VT-x 或 AMD-V/SVM 设置，不要随意更改其他固件选项。
3. 在 PowerShell 查看资源，确认系统盘和项目盘剩余空间。

```powershell
Get-CimInstance Win32_ComputerSystem |
  Select-Object NumberOfLogicalProcessors, TotalPhysicalMemory
Get-Volume | Select-Object DriveLetter, SizeRemaining, Size
```

内存和磁盘大小以字节显示。不要把全部核心、全部内存分配给虚拟机。对一台有 16 GB 内存的学习电脑，可从 Ubuntu 2 个 vCPU、4 GB 内存、40 GB 动态增长磁盘开始，再根据负载调整。这是实验建议，不是所有系统的最低要求。

### 分步拆解：为什么这样操作

**先查真实资源。** 任务管理器的性能页看总内存、CPU和虚拟化状态；磁盘剩余空间到资源管理器查看。命令输出的字节可除以1024三次粗略换成GiB，不必把长整数当作报错。

**只规划一台。** 16GB宿主可先给Ubuntu4GB，给宿主和其他应用留余量。不要照着别人“8核心、16GB”配置直接抄，别人的电脑可能资源更多。

**明确实验目的。** 这次只学Linux命令，就先不同时运行Windows客户机。把名称、版本、资源和网络模式写下来，之后排错才知道改过哪里。

## 实际应用：建立实验记录

给每台虚拟机记录用途、系统版本、资源、网络模式、快照时间和重要文件位置。例如“linux-lab / Ubuntu 24.04 LTS / 2 vCPU / 4 GB / NAT”。把工作文件另外备份，虚拟磁盘损坏时仍能找回成果。

```powershell
New-Item -ItemType Directory -Path .\vm-notes -Force
@'
名称: linux-lab
用途: 网络与 Linux 命令练习
网络: NAT
恢复点: 安装更新完成后创建
'@ | Set-Content -Encoding utf8 .\vm-notes\linux-lab.txt
```

这段代码只创建记录，不会创建虚拟机。练习时先明确一个目标，例如“学习 ip addr”，避免同时安装多个系统耗尽磁盘。

## 常见问题与解决方法

- **开机提示不支持虚拟化**：先查硬件能力、固件开关与软件系统要求，重启后再次验证。
- **电脑变卡**：减少同时运行的客户机，降低分配资源，并检查真实磁盘剩余空间。
- **动态磁盘为何仍占空间**：动态增长表示按使用量增长到上限，客户机删文件后通常不会自动等量缩小宿主文件。
- **能否代替备份**：不能，快照依赖基础虚拟磁盘，下一篇系列末尾会解释。

## 练习与参考答案

**练习：** 删除安装ISO后，虚拟机内的文件会一起消失吗？通常不会，文件在虚拟磁盘中。但若根本没有安装、只是从ISO试用启动，则要另看保存位置。

**练习：** 快照和独立备份能互相替代吗？不能。快照通常依赖原虚拟机文件链，宿主磁盘坏了也可能一起丢失。

## 知识总结

虚拟机适合重复安装、网络实验和软件测试。先规划资源，再安装系统，最后记录可恢复状态，能省去大量排错时间。

练习：写出你的宿主机资源与拟分配资源，确认宿主机仍有足够余量。
