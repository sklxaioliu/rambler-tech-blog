## 学习目标

理解安装图中“安装程序、配置服务、连接测试”分别在做什么；在 Windows 上从官方入口准备 MySQL；分清终端连接与图形工具连接；知道卸载前应该保留哪些资料。

## 先用一个例子理解

服务器像一直营业的资料室，客户端像进入资料室的窗口。把窗口图标装到桌面上，并不意味着资料室已经开门。安装 MySQL Server、启动服务和输入账号连接，是三个相关但不同的步骤。

例如你已经打开管理工具，却提示无法连接 `127.0.0.1:3306`。这时要检查服务、端口和地址，而不是反复新建一个连接名称。

## 基础知识

本系列以 MySQL 8.4 为学习基线。安装包、Windows 架构和运行要求以官方 Windows 安装页面为准，不照着旧版安装器截图寻找完全相同的按钮。

需要区分的文件位置包括：程序安装目录、数据目录和配置文件。程序目录放可执行文件，数据目录保存数据库内容，配置文件记录端口等设置。卸载程序以后，数据目录可能仍然存在，不能把它当作没有价值的缓存。

| 连接参数 | 例子 | 含义 |
| --- | --- | --- |
| 主机 | 127.0.0.1 | 连接本机的 TCP/IP 地址 |
| 端口 | 3306 | 常见默认端口，以实际配置为准 |
| 用户名 | root | 初始管理账号，不是所有应用都应使用的账号 |
| 密码 | 安装时自行设置 | 不写进命令、文章或截图 |
| 默认数据库 | 可先不填 | 连接后可以再选择 |

## 图示详解

![安装、启动、连接三个阶段](/img/mysql-guide/02.svg)

左边的安装阶段把程序放到电脑上；中间的服务阶段决定服务器是否正在监听；右边的连接阶段验证地址、账号和密码。旧安装截图里连续的多个窗口，实际是在完成这几个不同目标。

“服务启动成功”不能代替“账号连接成功”；连接成功也不表示当前账号拥有所有表的访问权。每个阶段都要用相应结果判断。

## 操作步骤

1. 打开 MySQL 官方下载入口，选择适用于 Windows 的 MySQL Community Server 8.4 安装包。
2. 按官方安装说明完成安装，再使用对应的配置工具配置服务器。记录实际端口、服务名、数据目录与管理账号。
3. 本地学习保持本机访问范围，不为了通过教程就额外开放公网端口。
4. 在 PowerShell 中检查服务。名称可能不同，先查询，再判断，不直接结束陌生进程。

```powershell
Get-Service -Name '*MySQL*'
Test-NetConnection 127.0.0.1 -Port 3306
```

5. 启动客户端。安装时没有加入 PATH，可以使用安装目录下 `mysql.exe` 的完整路径。

```powershell
mysql --version
mysql --host=127.0.0.1 --port=3306 --user=root --password
```

`--version` 显示客户端版本，不证明服务正在运行。第二条命令才尝试连接，随后在提示处输入密码；不要把密码接在 `--password=` 后面。进入 `mysql>` 后执行 `SELECT VERSION();`，查看真正连接的服务器版本。

6. 使用 Navicat 等图形工具时，创建 MySQL 连接，填写同样的主机、端口、账号与密码，执行连接测试，再打开查询编辑器。连接名称只是你给配置起的名字，不会在服务器上自动创建数据库。

## 实际应用

终端连接成功、图形工具失败时，比较两边参数，尤其是端口、用户名、默认数据库和认证兼容性。旧客户端可能不支持较新的认证方式，应优先使用兼容的客户端版本，不先削弱服务器认证设置。

卸载或重装之前，先导出需要的数据，记录账号和配置，验证备份能恢复。然后使用 Windows 的应用管理卸载相应程序。是否删除旧数据目录要单独决定；不要因为重装教程里有清理步骤，就删除不确定用途的数据库目录。

## 易错点

提示找不到 `mysql`，先检查程序路径；提示连接被拒绝，先检查服务与端口；提示 Access denied，则检查账号、密码、允许连接的主机以及认证方式。这些错误不能用同一种方法解决。

在 Windows 上使用本机 TCP 参数更便于保持示例一致。不同操作系统和客户端对 `localhost` 的连接方式可能不同，不能把其他系统的套接字规则直接套到 Windows。

## 知识总结

安装图的重点是各阶段的目标。用命令确认程序、网络和登录状态，记录实际配置；重装前保留并验证数据备份。
