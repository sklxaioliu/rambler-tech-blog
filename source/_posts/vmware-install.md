## 学习目标

能辨认官方来源、阅读系统要求、完成 Workstation Pro 安装，并知道下载、虚拟化和网络驱动问题应从哪里排查。本文是操作指引，并未在你的电脑上安装 VMware 或接受许可条款。

<!-- beginner-revision-2026-10-22 -->

## 先用一个例子理解

### 先装“管理房间的工具”，再装房间里的系统

Workstation 是宿主机上的虚拟化软件；Ubuntu和Windows才是客户机系统。安装Workstation成功后看不到Linux桌面，并不代表失败，因为你还没创建客户机。

网卡驱动像软件为虚拟房间铺设的内部道路，会影响客户机怎样联网。安装时出现虚拟网络组件，不是额外装了一台路由器。免费授权与可信来源也是两回事，免费软件仍应从官方渠道获取。

## 基础知识：版本与授权先核对

根据 Broadcom 官方说明，VMware Workstation Pro 自 2024 年 11 月起面向商业、教育和个人用户免费，适用版本及获取方式见官方知识库。免费使用不等于可以从任意网盘下载，也不代表 Windows 客户机自动获得系统许可证。

Workstation Pro 的 Windows 安装包安装在宿主机，Ubuntu ISO 则供客户机安装。不要混淆不同平台的安装文件。官网可能要求注册、登录或补充账户信息，按官方流程处理，避免下载所谓“免登录破解版”。

## 操作步骤

1. 阅读文末官方知识库，进入 Broadcom Support Portal 的下载入口，选择 VMware Workstation Pro 的 Windows 版本。
2. 对照所选版本发行说明检查受支持 Windows、CPU、内存和磁盘要求。旧硬件不要默认能运行所有新版本。
3. 右键安装包查看属性和数字签名，确认来源后运行安装程序。
4. 阅读许可条款，根据自己的意愿接受；保留合理默认设置。虚拟网卡驱动安装时可能短暂影响网络，先保存正在进行的工作。
5. 若提示重启，重启后打开 Workstation。具体组件选择与欢迎页以实际版本为准。
6. 查看 Help/About 中的版本信息，并记录到实验笔记。

在 PowerShell 可以辅助检查安装包签名：

```powershell
# 先把路径替换为实际下载文件，再执行
Get-AuthenticodeSignature 'C:\Users\你的用户名\Downloads\VMware-workstation安装包.exe' |
  Select-Object Status, SignerCertificate
```

这不是下载命令，示例路径不能直接照抄。签名状态异常时重新核对官方包，不要关闭 Windows 安全功能来绕过提示。

### 分步拆解：为什么这样操作

**先认文件来源。** 官方Windows安装包通常是可执行程序；Ubuntu下载的是ISO。扩展名和用途不同，不能把ISO当成宿主安装器双击一路安装。

**安装前保存工作。** 关闭重要编辑任务，记录原网络状态。运行可信安装包，按实际提示安装驱动，要求重启时完成重启；不确定的许可或选项先读说明，不点所谓破解按钮。

**安装后验证两处。** 一是程序能打开，二是About中版本可查看。然后准备客户机ISO。打开程序只证明软件可启动，不证明客户机网络、驱动与系统已经正常。

## 实际应用：准备隔离的学习网络

首次创建虚拟机时选择 NAT 通常更适合入门：客户机通过宿主机共享外网连接，不需要像桥接那样在真实局域网中成为独立设备。NAT 并非绝对隔离，客户机仍可能访问宿主及其他可路由目标，因此仍应保持系统更新。

安装完成后先只创建一台实验机，确认能进入 ISO 安装界面，再继续增加系统。若尚未准备 ISO，可先浏览新建向导并取消，不必强行创建空系统。

```powershell
# 查看当前 Windows 网络适配器，安装后可用于辨认新增虚拟网卡
Get-NetAdapter | Select-Object Name, InterfaceDescription, Status
```

输出名称因版本与配置不同，不要求一定与网上截图完全相同。

## 常见问题与解决方法

- **下载入口不可用**：检查是否登录正确账号、是否完成官方要求的信息，不使用来路不明镜像替代。
- **VT-x/AMD-V 提示**：先在任务管理器核对虚拟化。涉及 Hyper-V、VBS 的兼容问题时，查看对应 Workstation 版本文档；不要把关闭安全功能作为统一答案。
- **安装后网络异常**：先重启并检查适配器和 VPN 兼容性，保留错误信息；不要盲目重置整机网络。
- **要求许可证**：核对下载的是官方说明覆盖的版本和发行包，按当前授权说明处理，不使用激活补丁。

## 练习与参考答案

**练习：** 已装Workstation，但打开ISO时Windows提示不知道用什么程序，应该重装Workstation吗？不必先重装。应在新建虚拟机向导里把ISO作为客户机安装介质挂载。

**练习：** 遇到虚拟化兼容错误，是否直接关闭所有系统安全功能？不应该。先记录错误、核对硬件和软件版本文档，再针对性排查。

## 知识总结

可信下载、系统兼容、虚拟化启用、软件能启动，是安装阶段的四个检查点。不要把“安装完成”误当作“客户机系统已可用”。
