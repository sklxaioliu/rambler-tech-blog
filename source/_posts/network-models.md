## 学习目标

记住每层承担的职责，会把 HTTP、TCP、IP 和以太网放到合理层次，并按层定位问题。模型是理解工具，不是每个真实软件都必须严格遵循的代码结构。

<!-- beginner-revision-2026-10-22 -->

## 先用一个例子理解

### 分层像寄包裹时各自负责一件事

应用层决定包裹里要表达什么；传输层处理端到端的数据传送；网络层负责跨网络寻路；链路层处理当前相邻节点怎样交接。包装会一层层加上，到目的地再逐层处理，这有助于各部分独立改进。

OSI七层是理解框架，不是电脑里一定存在七个独立程序。TCP/IP常按四层讲，也有教材把物理层单列成五层，不必为了层数忘掉真正的问题：每部分承担什么责任。

HTTP 404表示已经收到了HTTP响应；网线拔掉则更靠近连接层面。不同现象应从不同方向查，不是所有错误都归为“网络断了”。

## 基础知识：为什么要分层

邮寄物品时，内容、包装、地址和运输各有职责。网络分层同样把不同问题分开：应用描述要做什么，传输层负责端到端传输，网络层处理寻址与跨网转发，链路层处理相邻节点间传输。

| OSI 层 | 核心问题 | 常见例子 |
| --- | --- | --- |
| 7 应用层 | 应用交换什么信息 | HTTP、DNS |
| 6 表示层 | 编码与表示如何理解 | 编码、序列化的概念 |
| 5 会话层 | 如何组织会话 | 会话管理的概念 |
| 4 传输层 | 端到端如何传输 | TCP、UDP |
| 3 网络层 | 包怎样跨网络到达 | IP |
| 2 数据链路层 | 相邻节点怎样传帧 | Ethernet、Wi-Fi 链路 |
| 1 物理层 | 比特怎样通过介质传输 | 电信号、光信号 |

常见 TCP/IP 四层模型把上面三层归为应用层，再分传输层、互联网层、链路层。有些教材把物理层单列，形成五层说法，并不需要争论哪一个数字才“唯一正确”。TLS 也不能简单机械地等同某一个 OSI 层；在 HTTP/1.1 和 HTTP/2 的常见 HTTPS 栈中，它位于 HTTP 与 TCP 之间。

## 操作步骤：跟踪一次 HTTPS 请求

1. 浏览器根据 URL 确定目标域名与协议。
2. 必要时解析 DNS，得到地址，或使用缓存结果。
3. 在典型 HTTP/1.1、HTTP/2 连接中建立 TCP，再协商 TLS，发送 HTTP 内容。HTTP/3 使用 QUIC/UDP，不能套用同样的 TCP 过程。
4. IP 层根据路由选择出口，链路层把帧交给下一跳。
5. 服务器接收后逐层处理，再返回响应。

```powershell
Resolve-DnsName example.com
Test-NetConnection example.com -Port 443
curl.exe -I https://example.com
```

这三条依次观察名称、TCP 端口和 HTTP 响应。`curl.exe` 显式调用 Windows 上的 curl，避免旧版 PowerShell 同名别名造成参数差异。命令输出取决于网络与站点实际响应。

### 分步拆解：为什么这样操作

**先看名称。** 运行DNS查询，知道example.com解析到什么记录。它只完成定位的一环。

**再看连接。** TCP443测试成功，说明该端口连接能建立，但不能证明账号能登录或页面内容正确。

**最后看应用。** curl -I取响应头，看到状态码后，判断是重定向、资源不存在还是服务错误。部分站点不支持HEAD，应结合实际请求，不只靠一次命令下结论。

**说清协议组合。** 常见HTTP/1.1或HTTP/2的HTTPS连接使用TCP与TLS；HTTP/3则是QUIC/UDP，不把熟悉的一条路径套给所有网站。

## 实际应用：分层缩小故障范围

假设网卡没有有效地址，优先查链路连接和 DHCP；如果地址正常但 DNS 失败，查解析配置；如果 TCP 443 成功但浏览器显示证书错误，查系统时间、证书链与域名，而不是更换网线。

TCP 端口成功仅说明连接建立，不代表 HTTP 业务正常。HTTP 500 表示服务器返回了应用层错误，此时网络路径至少已经让该响应到达。根据观察调整排错方向，避免一出问题就重置全部网络。

## 常见问题与解决方法

- **MAC 地址是否一路不变**：跨路由时链路层封装通常改变，IP 包由路由器继续转发；还要考虑 NAT 对地址的转换。
- **一个设备只属于一层吗**：家用路由器常承担多层功能，设备名称不能代替功能分析。
- **DNS 是传输层吗**：不是，它是应用层协议，可以使用 UDP、TCP 或加密传输方式。
- **所有 HTTPS 都走 TCP 吗**：不是，HTTP/3 基于 QUIC，运行于 UDP。

## 练习与参考答案

**练习：** 浏览器显示“证书已过期”，应先换网线吗？通常应先检查证书、域名与系统时间，因为已经进入安全连接相关环节。

**练习：** DNS属于传输层吗？不是，它属于应用层协议；其内容可通过不同传输方式承载。

## 知识总结

分层帮助表达“哪里出了什么问题”。记住 HTTP → TCP → IP → 链路这一常见路径，同时保留对其他协议组合的认识。

练习：把“网线断开”“端口被拒绝”“HTTP 404”分别放到最有帮助的排查层面。
