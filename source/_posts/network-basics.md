## 学习目标

解释局域网与互联网的区别，区分地址、路由和应用服务，能用三个 Windows 工具采集网络故障线索。这里只检查自己的电脑和允许访问的公共示例服务，不扫描他人的网络。

## 先用一个例子理解

### 一次访问网站，像按地址去一家店

域名是好记的店名，DNS帮助查地址；IP地址帮助找到网络位置，路由负责沿途选择方向，端口告诉你要找哪种服务。找到街道不等于商店开门，所以能解析域名不代表网页业务正常。

家用路由器常把多个功能装进一个盒子：Wi-Fi提供无线接入，交换功能连接局域网设备，路由把不同网络连起来。不要因为盒子只有一个，就认为这些步骤没有区别。

带宽像道路可同时容纳的车流量，延迟像一辆车到目的地要多久。车道多不保证第一辆车更快到，下载速度与游戏时延不能直接等同。

## 基础知识：网络让设备交换数据

局域网连接较小范围内的设备，互联网则由许多互联网络组成。交换机通常在二层根据 MAC 地址转发以太网帧；路由器在网络之间依据 IP 路由转发数据包。家用“路由器”常同时包含交换、Wi-Fi、DHCP 和 NAT 等功能，因此一个盒子可能承担多个角色。

IP 地址帮助定位网络接口；端口帮助识别主机上的传输层端点，例如 HTTPS 常用 TCP 443。域名便于人记忆，DNS 把名称解析为相关记录，其中 A 和 AAAA 分别用于 IPv4 和 IPv6 地址。

带宽描述链路可传输速率，延迟描述等待时间。下载快不等于游戏低延迟；丢包、无线干扰和拥塞也会影响体验。MB/s 与 Mb/s 单位不同，前者按字节，后者按比特计算。

## 操作步骤：画出自己的连接路径

1. 写下电脑通过网线还是 Wi-Fi 接入，以及是否经过 VPN。
2. 在 PowerShell 查看当前地址、掩码、网关与 DNS。
3. 检查名称解析，再检查应用端口。

```powershell
ipconfig /all
Resolve-DnsName example.com
Test-NetConnection example.com -Port 443
```

`ipconfig` 会列出多个适配器，虚拟网卡与 VPN 也在其中。关注当前有地址与默认网关的有效接口，不要随便挑第一项。

如果解析失败，先检查 DNS 与连接状态；如果解析成功而端口失败，原因可能在路由、防火墙、代理或目标服务，不能直接断言是 DNS 故障。

### 分步拆解：为什么这样操作

**先描述范围。** 是一个网站打不开，还是全部网站？同Wi-Fi另一台设备是否正常？这能帮助决定先查本机还是共享网络。

**再看有效网卡。** ipconfig /all会列很多接口，关注正在使用、具有有效地址和网关的那一项。虚拟网卡名字多，不等于网络被感染。

**分开验证两个问题。** Resolve-DnsName查“域名能否得到记录”；Test-NetConnection查“目标TCP端口能否建立连接”。前者失败先查解析，后者失败还可能与路由、服务或过滤有关。

**把结果写具体。** 记录错误原文与时间，比写“网不好”更便于继续排查。

## 实际应用：网站打不开时如何记录

先确认是一个网站失败还是全部失败，再比较同网络上的另一台设备。可以执行：

```powershell
ping 127.0.0.1
tracert example.com
```

回环测试只检查本机协议栈的一个很小部分；它成功不代表路由器和外网正常。`tracert` 显示路径探测结果，出现 `*` 可能只是设备不响应探测，不能把该跳直接认定为故障点。

记录“发生时间、网络方式、是否使用代理、解析结果、TCP 测试结果”，比“网络坏了”更有助于求助。日志可能包含本地地址和网络信息，分享前只保留必要内容。

## 常见问题与解决方法

- **Wi-Fi 显示已连接却不能上网**：连接到接入点与接入互联网是不同阶段，继续检查 DHCP、认证页、DNS 与出口。
- **ping 不通但网页能开**：目标可能不响应 ICMP，使用应用端口测试佐证。
- **所有网站都慢**：比较有线连接、其他设备和时段，排查无线干扰与共享带宽，不只看一次测速。
- **只有一个网站异常**：可能是目标服务、区域路由、证书或浏览器问题，应缩小范围。

## 练习与参考答案

**练习：** ping 127.0.0.1成功，可以证明家里路由器正常吗？不能，它主要验证本机回环通信，没有经过家里路由器。

**练习：** 只有某个网站出错，应先重置全机网络吗？先缩小范围，检查其他网站和目标服务，不急于改变所有配置。

## 知识总结

网络排错按连接、地址、路由、DNS、服务逐层收集证据。单条命令只能验证有限范围，不代表整个网络健康。

练习：用自己的话描述“输入域名后到服务器”的主要角色，并标出你能实际检查的部分。
