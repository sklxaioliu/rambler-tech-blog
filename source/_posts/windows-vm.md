## 学习目标

能从官方 ISO 安装 Windows 客户机，理解虚拟硬盘的边界，并完成网络、驱动与更新检查。请先安装支持目标系统的 Workstation Pro，并准备足够宿主资源与合法系统许可。

## 先用一个例子理解

### 安装器里的“磁盘”是哪一块，要先弄清

本教程新建的虚拟磁盘是宿主上的文件。客户机把它当硬盘使用，安装系统时格式化的是这个新建虚拟盘。我们不配置真实硬盘直通，因此也不应该在向导里随意选择宿主实体磁盘。

UEFI可理解为启动固件的一种方式；安全启动与TPM是系统安全要求的一部分，具体由软件提供受支持的虚拟硬件。它们不是为“让安装器别报错”而随便绕过的装饰选项。

VMware Tools像客户机与宿主之间的辅助桥梁，改善鼠标、显示和集成，不代替Windows系统更新。

## 基础知识：虚拟硬件也有系统要求

Windows 11 对 CPU、内存、存储、UEFI 与安全启动能力、TPM 2.0 有要求。虚拟机不自动免除这些条件。应使用 Workstation 提供的受支持虚拟 TPM 与固件设置，而不是绕过安装检查。

虚拟磁盘通常是宿主机上的文件。常规新建虚拟机中，Windows 安装器看到的是你新建的虚拟磁盘；若配置过物理磁盘直通，风险边界就不同。本教程仅使用新建虚拟磁盘，不使用真实硬盘直通。

## 操作步骤

1. 从 [微软 Windows 11 下载页](https://www.microsoft.com/software-download/windows11) 获取适合架构的官方 ISO，记录版本与文件位置。
2. 在 Workstation 新建向导选择稍后安装或指定 ISO，选择匹配的 Windows 客户机类型。取名 `windows-lab`，放在有充足空间的目录。
3. 按官方要求分配资源。宿主资源足够时，可从 2 个 vCPU、8 GB 内存、80 GB 磁盘进行学习；这不是最低配置承诺。
4. 核对 UEFI、安全启动支持和虚拟 TPM。软件可能要求先对虚拟机加密以添加 TPM，按版本官方指引保存恢复所需信息，不要丢失加密密码。
5. 挂载 ISO，网络先选 NAT，启动虚拟机。若出现从光盘启动提示，及时按键。
6. 进入 Windows 安装流程，选择新建的虚拟磁盘作为目标，按实际许可选择版本。不要在这里选择任何宿主真实磁盘。
7. 完成首次设置。账户与联网要求随发行版变化，遵循当前官方界面，不提供绕过脚本。
8. 进入桌面后安装 VMware Tools，安装系统更新，按提示重启。菜单入口因版本略有不同，通常可通过虚拟机菜单挂载 Tools 安装介质。

### 分步拆解：为什么这样操作

**向导里先记三件事。** 虚拟机名称、文件所在目录、虚拟磁盘大小。确认目录空间足够，并能在以后备份时找到整个虚拟机。

**第一次启动看介质。** 进入Windows安装界面说明已从ISO启动；如果提示找不到系统，先核对ISO是否连接和启动顺序。别立即换另一个来路不明镜像。

**安装目标再核对。** 对照自己创建的虚拟磁盘容量，确认是在客户机窗口内操作。安装完重启后断开ISO，避免又回到安装界面。

**进入桌面后再验证。** 运行客户机自己的ipconfig，而不是宿主的。两边都是Windows，窗口外观相似，但地址对应不同机器。

## 实际应用：检查实验机能否工作

在客户机 PowerShell 内执行，而非宿主机：

```powershell
Get-ComputerInfo | Select-Object WindowsProductName, OsVersion
ipconfig
Test-NetConnection example.com -Port 443
```

第一条确认客户机系统，第二条查看客户机 IP 和网关，第三条测试目标 HTTPS 端口的 TCP 连通性。结果依赖当地网络，并非所有环境都一定成功。屏幕分辨率随窗口调整、鼠标进出自然，通常说明 Tools 集成已经起作用，但仍应核对安装状态。

关机后创建一个“系统更新完成”的快照并写明时间。另行备份重要学习文件，别只依赖快照。

## 常见问题与解决方法

- **提示不满足要求**：检查客户机固件、TPM、分配资源及宿主/软件兼容要求，不建议绕过检测。
- **反复回到安装器**：安装完成后断开 ISO 或调整启动顺序，让虚拟磁盘优先。
- **没有网络**：确认虚拟网卡“已连接”和 NAT 模式，再检查客户机地址与 DHCP。
- **磁盘满了**：先检查宿主剩余空间；扩大虚拟磁盘后还需要在客户机内扩展分区，扩容前备份。

## 练习与参考答案

**练习：** 安装完每次启动仍回到“安装Windows”，先检查什么？先看是否仍从ISO启动，断开介质或调整启动顺序，再确认虚拟磁盘已有系统。

**练习：** 宿主能上网能证明客户机也能上网吗？不能。还需检查虚拟网卡连接、模式、客户机地址和应用连通性。

## 知识总结

从可信 ISO 开始，先核对虚拟硬件，再安装系统与 Tools，最后更新并建立恢复点。虚拟机软件免费与操作系统许可是两件独立的事。
