## 学习目标

理解 IPv4 与 CIDR，能计算常见 /24 子网的范围，区分默认网关与 DNS，并采集当前电脑配置。下列地址用于讲解，不是让你直接覆盖真实网卡设置。

## 先用一个例子理解

### IP和前缀要一起看，像门牌加街区范围

192.168.10.23/24中，地址像具体门牌，/24说明用前24位认定网络范围。对于这个例子，192.168.10开头的常规地址属于同一个/24网段。不能永远只看前三段，因为/16、/25等前缀的范围不同。

默认网关像出街区的出口，DNS像查询店名的通讯录。它们可能由同一台设备提供，但“出口在哪里”和“店名对应哪里”是两个问题。

DHCP像前台分配房号：它可自动给设备发地址、掩码等配置。随便手写一个看起来顺眼的地址，可能撞上别人已用的号码。

## 基础知识

IPv4 有 32 位，常表示为四个 0～255 的十进制数。`192.168.10.23/24` 中 `/24` 表示前 24 位是网络前缀，对应掩码 `255.255.255.0`。同一网段里的设备通常可以通过链路直接通信；发往其他网络时，主机按路由表选择下一跳。

对于常规的 `192.168.10.0/24` 子网，网络地址是 `.0`，广播地址是 `.255`，普通主机地址通常为 `.1` 到 `.254`，共 254 个。不能把“减去两个”推广到所有情形，例如 /31 点对点链路与 /32 主机路由有不同用途。

默认网关是没有更具体匹配路由时使用的下一跳，不负责自动把域名翻译成地址。DNS 做名称解析，两者可以恰好在同一设备上，但职责不同。家用网常通过 DHCP 自动领取这些参数。

## 操作步骤：只观察，先不修改

```powershell
ipconfig /all
Get-NetIPConfiguration
Get-NetRoute -AddressFamily IPv4 |
  Sort-Object DestinationPrefix, RouteMetric |
  Select-Object DestinationPrefix, NextHop, InterfaceAlias, RouteMetric
```

1. 找到正在使用的物理或 VPN 接口。
2. 记录 IPv4、前缀长度、默认网关与 DNS。
3. 在路由结果中查 `0.0.0.0/0`，它代表默认路由。
4. 如果有 VPN 或多个网卡，不要只靠地址前三段猜流量走向，要结合前缀长度、路由和接口优先级判断。

### 分步拆解：为什么这样操作

**先观察不要改。** 运行ipconfig，抄下当前IP、掩码、网关与DNS。这里只记录，不能把文章示例直接填进真实办公网。

**用/24样例手算。** 192.168.10.23的网络地址是192.168.10.0，普通主机通常用.1到.254，.255为广播。这是当前前缀下的例子，不能推广到所有子网。

**比较目的地址。** 到192.168.10.80通常同网段；到192.168.11.80则要查路由。系统按路由表选择更具体匹配，不能只看到默认网关就认为所有流量都一定经过它。

**再用Python验证。** 代码里的in是在问“这个地址是否属于该网络”，不会修改网卡。

## 实际应用：判断两个实验地址是否同网段

设备 A 为 `192.168.10.23/24`，B 为 `192.168.10.80/24`，网络前缀相同，通常可直接通信；C 为 `192.168.11.80/24`，需要路由。若把 A 改成 `/16`，它会把更多地址视为同链路，错误掩码可能导致它向错误位置寻找邻居。

下面的 Python 标准库示例可帮助检查计算，需先有 Python；它不会修改网卡：

```python
from ipaddress import ip_interface, ip_address

iface = ip_interface('192.168.10.23/24')
print(iface.network)
print(iface.network.netmask)
print(ip_address('192.168.10.80') in iface.network)
print(ip_address('192.168.11.80') in iface.network)
```

示例的最后两个判断分别应为 True 和 False。项目运行不要求 Python，手算前缀也能完成练习。

## 常见问题与解决方法

- **手动指定 IP 后断网**：可能地址冲突、掩码或网关错误。先恢复原来记录的配置；在受管网络中向管理员申请地址。
- **169.254 开头**：可能是 DHCP 未成功时得到的链路本地地址，需要检查 DHCP 获取路径。
- **私有地址能否直接从互联网访问**：IPv4 私有地址通常不可在公网直接路由，外部访问需要另行设计，不能仅凭设置 IP 实现。
- **IPv6 为什么没有掩码写法**：IPv6 常使用前缀长度表示，同样有路由，但没有 IPv4 这种广播地址机制。

## 练习与参考答案

**练习：** 192.168.20.5/24与192.168.20.200/24同网段吗？是。与192.168.21.5/24呢？不是，需要相应路由。

**练习：** 同样的192.168.20.5改为/16后，网络范围还一样吗？不一样，网络前缀变短，包含范围变大。改变掩码会改变本机的判断，不能随便试在真实网络上。

## 知识总结

IP 与前缀一起决定网络位置；网关承担跨网下一跳；DNS 解析名称。先记录配置再做实验，避免把示例地址写进真实办公网络。
